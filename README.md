# Student Course Registration System

## Overview

A web-based student course registration application developed using ASP.NET Core MVC. The application allows students to browse available courses, manage their registrations, and submit registration requests. Administrators can review, approve, and deny registration requests.

## Features

### Student Features
- Student account registration and authentication.
- Browse available courses by semester.
- Search and sort available courses.
- Validate course prerequisites before registration.
- Add and drop course registrations.

### Administrator Features
- Administrator authentication and authorization.
- View student registration requests.
- Approve or deny registration requests.

## Technologies Used

- **Language:** C#
- **Framework:** ASP.NET Core MVC
- **Database:** SQL Server
- **ORM:** Entity Framework Core
- **Authentication:** ASP.NET Core Identity
- **Frontend:** HTML, CSS, JavaScript, Razor Views

## Getting Started

### Prerequisites
- .NET SDK
- SQL Server
- Visual Studio or Visual Studio Code

### Installation

1. Clone the repository.
2. Configure your database connection string.
3. Apply Entity Framework Core migrations.
4. Run the application.
